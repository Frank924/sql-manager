# SQL Manager 界面与交互验证

## 交付操作

- **环境台账** 展示每个环境的代码版本、SQL 执行进度和待处理脚本。
- **发布版本** 支持编排脚本顺序。发布后锁定版本清单与脚本。
- **交付包** 支持预览目标版本差集、下载 ZIP，并逐文件登记结果。
- **异常处理** 在出现失败或部分执行时将环境标为待核实，并暂停后续升级包导出。登记修正保留原因和历史记录。

## 布局与表单

- 桌面视图同时显示环境列表和所选环境的详情。
- 窄屏将详情移到列表下方，并折叠侧栏。宽表格可在自身区域横向滚动。
- 上传表单提供文件及类型字段。执行登记表单要求执行人和执行时间，异常与修正需要填写说明。
- 环境状态同时使用文字和颜色标识。
